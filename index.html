Opsi proses

Tanggal PTAG ditentukan per PRDCD dari tanggal TGL_AKHIR terbaru yang valid. Tanggal pada judul dan nama file ekspor otomatis mengikuti tanggal saat tombol Proses MSTSTK dijalankan. Hasil Excel mengikuti susunan, lebar kolom, gaya header, border, dan format kolom dari Master Stock acuan.

Hasil proses

Selesai

File Excel mengikuti format tabel Master Stock acuan, termasuk lebar kolom, dua baris header, merge cell, border, dan format sel. Tanggal judul dan nama file menggunakan tanggal proses.
